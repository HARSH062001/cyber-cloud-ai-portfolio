# Safety Policy

## Rules

- Never send emails without approval.
- Never apply to jobs without approval.
- Never post to LinkedIn/X without approval.
- Never delete Notion/GitHub data without approval.
- Never expose tokens, secrets, credentials, API keys, OAuth tokens, or private data.
- Always show a summary before write actions.
- Prefer drafts, branches, pull requests, or pending entries over irreversible actions.
- For Notion writes, show the target database, exact fields, and row/page summary first.
- For GitHub writes, show the target repo, branch/file path, and summary first.
- For public portfolio content, do not fake results, screenshots, certifications, work experience, or completed projects.
