# Study Tracker Update

## Purpose

Record study sessions for PTE, Security+, GRC, or related cyber learning.

## When to Use

Use when the user completes study work, wants to log progress, or wants a study session summarized into tracker format.

## Inputs Required

- Study topic
- Subject area
- Duration
- Score or outcome if available
- Weak area if any
- Next review action

## Output Format

- Topic
- Category
- Time spent
- Score or status
- Weak area
- Next review action
- Brief study summary

## Notion Database

`Study Tracker`

## GitHub Impact

None by default.

## Discord Channel

`#dept-clo`

## Human Approval Required

No. Standard study logging is low risk.

## Safety Notes

Do not invent scores or certifications. If a result is unknown, mark it as unknown or pending.
