# Daily Journal Entry

## Purpose

Create or prepare a structured daily journal update covering wins, blockers, and next actions.

## When to Use

Use when the user asks to log the day, capture progress, record blockers, or prepare an end-of-day update.

## Inputs Required

- Date
- Main work completed
- Wins
- Blockers
- Next actions
- Optional notes

## Output Format

- Entry title
- Date
- Wins
- Blockers
- Next actions
- Notes
- Short plain-English summary

## Notion Database

`Daily Journal`

## GitHub Impact

None by default.

## Discord Channel

`#jim-office`

## Human Approval Required

No. Normal journaling is low risk unless it includes sensitive or public-facing content.

## Safety Notes

Show the target database and exact row fields before writing. Avoid including secrets, private credentials, or personal data beyond what is needed.
