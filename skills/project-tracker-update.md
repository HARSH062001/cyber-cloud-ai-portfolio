# Project Tracker Update

## Purpose

Update the status, scope, and next steps of cybersecurity portfolio projects.

## When to Use

Use when the user starts a new project, changes project status, adds a repo link, or wants project progress captured systematically.

## Inputs Required

- Project name
- Status
- Level
- Tools used or planned
- Notes
- GitHub link if available

## Output Format

- Project name
- Status
- Level
- Tools or skills
- GitHub link
- Notes
- Next milestone

## Notion Database

`Project Tracker`

## GitHub Impact

May reference project folders or repo links, but does not need to modify GitHub unless explicitly requested.

## Discord Channel

`#dept-cto`

## Human Approval Required

No for tracker-only updates. Yes if the workflow also changes GitHub files.

## Safety Notes

Do not mark planned work as completed. Separate tracker updates from actual code or documentation writes unless approved.
