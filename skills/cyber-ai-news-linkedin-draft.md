# Cyber/AI News LinkedIn Draft

## Purpose

Turn a relevant cybersecurity or AI security development into a clean, honest draft for future LinkedIn content.

## When to Use

Use when the user shares an article, asks for a LinkedIn draft, or wants a thought piece based on current cyber or AI news.

## Inputs Required

- Source article or topic
- Main angle
- Intended audience
- Tone or takeaway
- Optional call to action

## Output Format

- Hook
- Main point
- Personal learning angle
- Closing takeaway
- Optional CTA
- Safety check summary

## Notion Database

No required Notion database yet. Future content database can be added later.

## GitHub Impact

None by default.

## Discord Channel

`#dept-cio`

## Human Approval Required

Yes. Public posting and personal-brand content require review.

## Safety Notes

Draft only unless explicitly approved for posting. Do not fabricate expertise, results, or firsthand incident involvement.
