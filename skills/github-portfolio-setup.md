# GitHub Portfolio Setup

## Purpose

Create or expand beginner-friendly GitHub portfolio structure for cybersecurity, cloud security, GRC, and AI security learning projects.

## When to Use

Use when the user asks to create project folders, write portfolio README files, organize a repository, or build documentation-first project scaffolding.

## Inputs Required

- Target repository
- Project list
- Status for each project
- README structure or template
- Any overwrite constraints

## Output Format

- Planned file tree
- Main README summary
- Project README summary
- Verification checklist after write

## Notion Database

Optional reference to `Project Tracker`, but no Notion update is required by default.

## GitHub Impact

May touch `HARSH062001/cyber-cloud-ai-portfolio`, including root documentation and project folders.

## Discord Channel

`#dept-cto`

## Human Approval Required

Yes. This workflow changes public GitHub content and may overwrite existing docs.

## Safety Notes

Inspect the repo first. Show target repo, branch, file paths, and write summary before changes. Do not fake project completion, screenshots, findings, or experience.
