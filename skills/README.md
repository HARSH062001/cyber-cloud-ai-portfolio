# Harsh Inc AI Skills Library

This folder stores reusable workflows and operating instructions for Codex, OpenClaw, Hermes, and future agents working inside the Harsh Inc system.

## Skill Index

| Skill | Purpose | Main database/tool | Approval required |
| --- | --- | --- | --- |
| `harsh-inc-context.md` | Shared operating context for all agents | Cross-system context | No |
| `safety-policy.md` | Shared safety and approval rules | Cross-system policy | No |
| `daily-journal-entry.md` | Log daily progress, wins, blockers, and next steps | Notion `Daily Journal` | No |
| `study-tracker-update.md` | Record study sessions and learning progress | Notion `Study Tracker` | No |
| `job-report.md` | Track job applications, follow-ups, and outcomes | Notion `Job Tracker` | Yes |
| `project-tracker-update.md` | Update portfolio and learning project status | Notion `Project Tracker` | No |
| `github-portfolio-setup.md` | Create or expand GitHub portfolio structure safely | GitHub repo and project folders | Yes |
| `security-plus-quiz.md` | Run lightweight Security+ review and capture weak areas | Notion `Study Tracker` | No |
| `pte-practice-plan.md` | Build a focused PTE practice plan | Notion `Study Tracker` | No |
| `cyber-ai-news-linkedin-draft.md` | Turn relevant news into a draft post | Draft text first, optional future content DB | Yes |
| `startup-research-brief.md` | Capture startup ideas without distracting from core goals | Notion `Startup Research` | No |
| `end-of-day-review.md` | Close the day with review and tomorrow priorities | Notion `Daily Journal` | No |

## Usage Rule

Before executing a recurring workflow, agents should read `harsh-inc-context.md`, `safety-policy.md`, and the relevant skill file.
