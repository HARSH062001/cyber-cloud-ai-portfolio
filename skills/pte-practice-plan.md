# PTE Practice Plan

## Purpose

Create a focused PTE study plan that targets the current weak area without overcomplicating the workflow.

## When to Use

Use when the user asks for a daily PTE plan, section-specific practice plan, or time-boxed study routine.

## Inputs Required

- Current weak section or score range
- Available time
- Practice focus for today
- Optional recent mistakes

## Output Format

- Study objective
- Section focus
- Time blocks
- Exercise list
- Review method
- Next action summary

No. Planning study work is low risk.

## Safety Notes

Prefer practical exercises over bloated plans. Keep the plan realistic for the same day.
