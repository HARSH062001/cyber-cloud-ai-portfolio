# Security+ Quiz

## Purpose

Run a lightweight Security+ review loop and capture weak concepts for follow-up study.

## When to Use

Use when the user asks for quiz questions, concept checks, rapid revision, or a weak-topic review for Security+ or GRC basics.

## Inputs Required

- Domain or topic
- Number of questions
- User answers or performance notes
- Weak areas to capture

## Output Format

- Question set or quiz summary
- Answer review
- Score if known
- Weak topics
- Recommended next review tasks

Do not claim exam readiness from a tiny sample. Keep performance notes honest and avoid fabricated scores.
