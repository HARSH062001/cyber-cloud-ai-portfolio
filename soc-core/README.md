# SOC Core

SOC Core is my practical learning framework for becoming job-ready for SOC Analyst and Junior Security Analyst roles.

I understand cybersecurity better when I connect theory with hands-on implementation.

Every SOC Core topic should connect:

1. Theory
2. Log source
3. Detection idea
4. Triage steps
5. Incident report
6. GitHub evidence
7. LinkedIn post idea
8. Resume bullet

This framework is designed to help me turn study into visible portfolio evidence instead of disconnected notes.

## Main Focus Areas

- SOC analyst foundations
- log analysis
- alert triage
- incident response
- SIEM workflows
- cloud logs for SOC
- AI-assisted SOC workflows

## How I Will Use SOC Core

For each topic, I will study the theory, understand the relevant log source, think through detection ideas, practice triage, and document the work in a way that can later support GitHub evidence, LinkedIn content, and resume bullets.

SOC Core is a learning system. It does not claim these projects are completed.
