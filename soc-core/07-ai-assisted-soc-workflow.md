# 07 AI-Assisted SOC Workflow

AI can help SOC analysts work faster and more clearly, but it should assist analysis rather than replace judgement.

## How AI Can Assist SOC Analysts

AI can help organise information, explain technical details, suggest investigation steps, and draft structured outputs from raw evidence.

## Useful Assistance Areas

- summarising logs
- drafting incident reports
- explaining alerts in plain language
- generating triage checklists
- converting rough notes into clearer analyst summaries

## Risks of AI in SOC Work

- hallucination
- data leakage
- over-reliance
- inaccurate technical interpretation
- missing business context

## Safe AI Use Rule

AI assists, human verifies.

## Portfolio Project Ideas Using AI Safely

- create a prompt workflow for turning alert notes into draft incident summaries
- compare raw logs with AI-generated summaries and verify differences
- build a checklist that requires human review before any conclusion is accepted
- document where AI helps speed up triage and where analyst judgement is still required
