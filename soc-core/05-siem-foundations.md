# 05 SIEM Foundations

A SIEM collects, normalises, searches, and correlates logs so analysts can detect and investigate suspicious activity more efficiently.

## What a SIEM Is

A SIEM acts as a central place to bring together security-relevant data from many systems and turn it into searchable and alertable visibility.

## Microsoft Sentinel

Microsoft Sentinel is a cloud-native SIEM and SOAR platform that supports data collection, analytics, workbooks, incidents, and investigation workflows.

## Splunk

Splunk is widely used for log search, dashboards, alerts, and security investigations. Learning how to think in queries and fields is valuable even when tooling changes.

## Search Queries

Search queries help analysts filter events, pivot across evidence, and test whether suspicious patterns are isolated or widespread.

## Dashboards

Dashboards help visualise trends, volumes, and risk patterns. They can support monitoring, reporting, and investigation starting points.

## Correlation Rules

Correlation rules combine multiple signals to identify suspicious behaviour that may not be obvious in a single event.

## Use Cases

Examples include:

- repeated failed logins
- impossible travel or suspicious sign-in patterns
- admin privilege changes
- suspicious PowerShell or command execution
- unusual outbound traffic

## SOC Analyst Portfolio Ideas

- document a simple alert triage workflow
- write sample query ideas for suspicious logins
- create a mini incident summary from sample events
- explain how a SIEM use case maps to analyst actions
