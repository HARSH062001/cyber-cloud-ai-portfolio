# 06 Cloud Logs for SOC

SOC analysts need basic cloud knowledge because modern environments often include cloud identities, cloud services, and cloud-native alerts.

## Why SOC Analysts Need Basic Cloud Knowledge

Even if cloud security is not the first job title, analysts still need to understand how suspicious cloud activity appears in logs and alerts.

## AWS CloudTrail

CloudTrail helps analysts review API activity, administrative changes, and identity-related actions inside AWS.

## AWS GuardDuty

GuardDuty produces findings that can help analysts recognise suspicious behaviour, risky access patterns, and possible compromise indicators.

## Azure Sign-In Logs

Azure sign-in logs are useful for investigating authentication behaviour, suspicious login attempts, and identity anomalies.

## Microsoft Sentinel

Sentinel can bring together cloud log data, identity signals, and alerts into a central SOC workflow.

## Suspicious Cloud Activity Examples

- unusual console logins
- repeated denied API actions
- privilege changes in IAM
- new access keys or risky identity changes
- suspicious cloud resource access patterns

## Future Career Growth Connection

This cloud knowledge supports SOC investigations today and creates a stronger long-term pathway into cloud security work later.
