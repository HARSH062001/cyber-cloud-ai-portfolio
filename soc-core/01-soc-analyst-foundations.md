# 01 SOC Analyst Foundations

A Security Operations Center (SOC) analyst helps monitor, investigate, and respond to suspicious activity across an organisation's environment.

## What a SOC Analyst Does

A SOC analyst watches for signs of malicious or risky behaviour, reviews alerts, investigates available evidence, and helps escalate or document incidents clearly.

## Monitoring

Monitoring means reviewing telemetry from systems such as SIEM platforms, EDR tools, firewalls, identity systems, email security tools, and cloud logs.

## Alert Triage

Alert triage is the process of deciding whether an alert is likely real, how urgent it is, and what evidence is needed next.

## Escalation

Escalation happens when an alert is serious enough, unclear enough, or high-impact enough that it needs support from a senior analyst, incident responder, cloud team, or another internal stakeholder.

## Incident Documentation

Strong documentation helps the SOC explain what happened, what was observed, what was done, and what still needs follow-up.

## False Positives

A false positive is an alert that looks suspicious but turns out to be benign. Analysts need to reduce wasted effort while still avoiding missed threats.

## Basic Threat Categories

Entry-level analysts should be familiar with common threat categories such as:

- phishing
- malware
- credential abuse
- privilege escalation
- suspicious logins
- lateral movement
- data exfiltration
- insider misuse

## Common Tools

- SIEM
- EDR
- ticketing systems
- threat intelligence sources
- email security tools
- firewall and proxy logs
- identity and access logs

## Entry-Level Skills Checklist

- understand how alerts are generated
- read and interpret common log fields
- write short investigation summaries
- distinguish severity from priority
- identify likely false positives
- know when to escalate
- understand basic incident response flow
- communicate findings clearly

## Interview Questions

- What does a SOC analyst do day to day?
- What is the difference between a true positive and a false positive?
- How would you triage a suspicious login alert?
- When should an alert be escalated?
- Why is documentation important in incident handling?
- What tools are commonly used in a SOC?
